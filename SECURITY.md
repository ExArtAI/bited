# Безопасность / Security

Не публикуйте уязвимости, ключи, личные проекты или содержимое переписок в публичных Issues.

Используйте приватное сообщение об уязвимости GitHub: https://github.com/ExArtAI/bited/security/advisories/new . Если приватная форма недоступна, не публикуйте чувствительные детали; запросите безопасный канал без описания эксплуатации.

Публичной сборки пока нет; сроки ответа не гарантируются.

Do not disclose vulnerabilities or credentials in public issues. Use GitHub private vulnerability reporting at the link above. If unavailable, request a safe contact method without disclosing exploitation details. No response-time guarantee is made.
