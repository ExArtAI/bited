# Bited

### Your vision. Not necessarily on your own.

**Bited is a local creative workspace with an optional AI companion.** Organize a fictional world, keep track of connections, and discuss your work without giving up authorship or control.

Bited is part of **Plexus**, an author-led direction exploring AI that supports human participation in creativity rather than replacing it.

## Development status

**There is no public application build in this repository yet.** v0.4 is undergoing internal testing. v0.5 is the target for a first public preview, subject to testing; no release date is announced.

This repository is a **public showcase and feedback tracker**, not the application's source repository. No private worlds, conversations or API credentials are included.

## Why Bited?

Large creative ideas are difficult to hold together. Notes scatter across files, questions get lost, and returning after a break takes effort.

Bited brings materials and decisions into one workspace. Ask the optional AI companion to discuss a question, explore alternatives or review selected material. It can make mistakes and does not replace human relationships, editors or professional judgment.

## Internal prototype

Lore cards and folders, relationship board, searchable timeline, tasks and recorded results, project growth view, optional API chat, text extraction with preview, local `.bited` worlds and backups.

These are prototype capabilities, not a claim of public-release readiness. Real local-model configurations and UI scenarios still need testing.

## v0.5 direction — planned, not yet released

- Manuscript workspace for chapters, scenes and textual game episodes.
- Author markers and a work queue.
- Focused AI text review, premise analysis and implementation suggestions.
- Three example projects: fan fiction, a book and a game.
- Clearer navigation, a collapsed-by-default chat and a more expressive growth view.
- External local-model testing and smaller, more manageable AI jobs.

Plans may change. Bundled inference engines and automatic model downloads are deferred.

## Principles

- The author decides: suggestions do not silently become canon or tasks.
- A useful workspace without AI.
- No penalties for breaks; progress is not a talent score.
- Explicit, bounded context rather than sending an entire manuscript for every question.
- Local storage does not necessarily mean local inference: cloud requests send selected text to the configured provider. No hidden cloud fallback.

## Free to use, closed source

The intended distribution model is **a free application with closed source code**, not open source. User-created worlds and writing are not transferred to the project.

Third-party cloud API usage may cost money. Local models require suitable hardware and setup. Application terms will accompany the first public release. This showcase grants no license to application source, branding or creative assets; see [RIGHTS.md](RIGHTS.md).
